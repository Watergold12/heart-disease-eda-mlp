# Heart Disease EDA & Deep Learning Project

## Overview
Exploratory Data Analysis and Visualization of the Cleveland Heart Disease Dataset,
with a Multi-Layer Perceptron (MLP) deep learning classifier.

## Dataset
Cleveland Heart Disease Dataset — 303 records, 14 features
Source: UCI Machine Learning Repository / Kaggle

## Tech Stack
Python 3.10 | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | TensorFlow/Keras

## Results
- Test Accuracy: ~86%
- AUC Score: ~0.93
- Key features: ca, cp, thalach, oldpeak

## Project Structure
EDA_Heart_Disease.ipynb    → Main notebook (EDA + Model)
